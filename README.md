## Evidence standard

The repository follows one rule that matters more than any branding language: **evidence before hype**.

Public claims distinguish among:

- **Verified** — supported by governed evidence;
- **In development** — real work underway without a completed deployment claim;
- **Research direction** — an area being studied or designed, not represented as delivered capability.

The site does not imply customer adoption, production deployment, certification, partnerships, clearances, patents, awards, or institutional endorsement without support.
